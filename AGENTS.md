# Instruksjoner for arbeid i matte10

Les `SITE_SPEC.md` før endringer. Dette repositoryet er et offentlig elevnettsted for matematikk på 10. trinn, publisert med GitHub Pages fra `main` og rotmappen.

- Følg felles navigasjon, visuell stil og tilgjengelighetskrav i spesifikasjonen på alle nye sider.
- Hold forklaringer enkle, og la oppgaver ha progresjon. Ikke publiser nye fasiter uten uttrykkelig instruksjon.
- Oppdater den felles begrepsbanken når nye temaer legges til; gjenbruk begreper og stabile ID-er.
- Ikke last opp lærerressurser, vurderingsnotater, elevopplysninger eller upublisert materiale.
- Bevar eksisterende nettadresser og tidligere prøvefasit. Bruk relative lenker slik at `/matte10/` fungerer.
- Test intern navigasjon både med og uten fullskjerm, brødsmuler, Hjem, innholdsmeny og mobil før publisering.
- Dersom generatoren i arbeidsmiljøet er tilgjengelig, oppdater kildene og bygg på nytt. Ikke rett bare genererte HTML-filer og la generatoren overskrive rettelsen senere. Se kildebeskrivelsen i SITE_SPEC.md.
