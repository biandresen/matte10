Forkorting av algebraiske brøker

Del oppe og nede på det samme

Tema 2 av 6 · Teori: 15 minutter

Dette skal du lære

Jeg kan forkorte felles faktorer og se at en nevner ikke kan være null.

Start med en enkel idé

En halv pizza er like mye som to firedeler. Derfor er 2/4 og 1/2 like store. Med bokstaver gjør vi det samme: vi deler både det som står over brøkstreken og det som står under, på samme faktor.

Regelen med egne ord

Telleren står over brøkstreken. Nevneren står under. Faktoriser først hvis det er flere ledd. Forkort bare en faktor som hele telleren og hele nevneren har felles.

Du kan ikke dele på 0. Hvis x står i nevneren, må x være ulik 0. Tegnet ≠ betyr «er ikke lik».

Eksempler – ett steg om gangen

Se på uttrykket. Tenk på første steg før du åpner løsningen.

Samme faktor oppe og nede

6x9x
Vis framgangsmåten

6x = 3x · 2 og 9x = 3x · 3. Del oppe og nede på 3x.

Mellomsteg

6x9x = 3x · 23x · 3
Svar
23

Gyldige verdier: x ≠ 0. Den opprinnelige nevneren kan ikke være 0, også etter forkorting.

Flere ledd i telleren

4x + 84
Vis framgangsmåten

Sett 4 utenfor parentesen. Hele telleren har da faktoren 4, som kan forkortes mot 4 i nevneren.

Mellomsteg

4x + 84 = 4(x + 2)4
Svar
x + 2

En hel parentes kan være felles

3x − 65x² − 10x
Vis framgangsmåten

Faktoriser begge: 3(x − 2) og 5x(x − 2). Del oppe og nede på hele parentesen x − 2.

Mellomsteg

3x − 65x² − 10x = 3(x − 2)5x(x − 2)
Svar
35x

Gyldige verdier: x ≠ 0 og x ≠ 2. Den opprinnelige nevneren kan ikke være 0, også etter forkorting.

En vanlig feil – og hvordan du unngår den

I brøken x + 2x kan du ikke stryke x: x er ikke en faktor i hele telleren. Sett x = 2: brøken blir 4/2 = 2, ikke 3.

Prøv muntlig før øvingsarket

Forkort så mye som mulig.

8x²4x
Vis svaret og forklaringen

x² har to x-faktorer. Del oppe og nede på 4x. Én x blir igjen.

Mellomsteg

8x²4x = 4x · 2x4x
Svar
2x

Gyldige verdier: x ≠ 0. Den opprinnelige nevneren kan ikke være 0, også etter forkorting.
