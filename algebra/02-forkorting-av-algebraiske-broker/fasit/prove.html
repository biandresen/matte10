6x + 126 = 6(x + 2)6

Oppgave 5 · 3 poeng

Forkort så mye som mulig. Hvilken verdi kan x ikke ha?

3x² + 6x3x
Vis svar og framgangsmåte

Sett 3x utenfor parentesen. Forkort med 3x. Den opprinnelige nevneren er 0 når x = 0.

Mellomsteg

3x² + 6x3x = 3x(x + 2)3x
Svar
x + 2

Gyldige verdier: x ≠ 0. Den opprinnelige nevneren kan ikke være 0, også etter forkorting.
