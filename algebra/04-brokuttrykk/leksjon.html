Sammensetting av brøkuttrykk

Finn fellesnevner før du legger sammen

Tema 4 av 6 · Teori: 15 minutter

Dette skal du lære

Jeg kan legge sammen og trekke fra brøkuttrykk med lik og ulik nevner.

Start med en enkel idé

En halv og en firedel må skrives som like store biter før vi teller dem sammen. En halv er to firedeler. Dermed er 1/2 + 1/4 = 3/4. Bokstaver følger den samme regelen.

Regelen med egne ord

1. Finn en fellesnevner. 2. Gang teller og nevner med samme faktor for å få denne nevneren. 3. Legg sammen eller trekk fra tellerne. Behold nevneren. 4. Forkort hvis du kan.

Når nevnerne er like, regner du bare med tellerne. Ved minus foran en teller med flere ledd bruker du parentes.

Eksempler – ett steg om gangen

Se på uttrykket. Tenk på første steg før du åpner løsningen.

Lik nevner

x5 + 2x5
Vis framgangsmåten

Nevnerne er like. Legg sammen x + 2x i telleren.

Mellomsteg

x5 + 2x5 = x + 2x5
Svar
3x5

Ulik nevner

x2 + x4
Vis framgangsmåten

Fellesnevneren er 4. Gang teller og nevner i første brøk med 2.

Mellomsteg

x2 + x4 = 2x4 + x4
Svar
3x4

Minus foran hele telleren

x + 35 − x + 15
Vis framgangsmåten

Bruk parentes rundt telleren som trekkes fra. x + 3 − x − 1 = 2.

Mellomsteg

x + 35 − x + 15 = (x + 3) − (x + 1)5
Svar
25

Bokstav i nevneren

1x + 12
Vis framgangsmåten

Fellesnevneren er 2x. Gang første brøk med 2 oppe og nede, og andre med x oppe og nede.

Mellomsteg

1x + 12 = 22x + x2x
Svar
x + 22x

Gyldige verdier: x ≠ 0. Den opprinnelige nevneren kan ikke være 0, også etter forkorting.

Ekstra: faktoriser nevnerne

x3x + 3 + 42x + 2
Vis framgangsmåten

Nevnerne er 3(x + 1) og 2(x + 1). Fellesnevner er 6(x + 1). Utvid første teller til 2x og andre til 12. Til slutt forkorter du med 2.

Mellomsteg

x3x + 3 + 42x + 2 = 2x + 126(x + 1)
Svar
x + 63(x + 1)

Gyldige verdier: x ≠ −1. Den opprinnelige nevneren kan ikke være 0, også etter forkorting.

En vanlig feil – og hvordan du unngår den

x3 + x3 er 2x3, ikke 2x6. Nevneren forteller størrelsen på bitene; den skal ikke legges sammen.

Prøv muntlig før øvingsarket

Regn ut og trekk sammen.

x3 + x6
Vis svaret og forklaringen

Utvid første brøk med 2. Da får du 3x/6, som forkortes med 3.

Mellomsteg

x3 + x6 = 2x6 + x6
Svar
x2
Sjekkliste før du går videre

Bruk dette som en egenvurdering. Avkrysningene lagres ikke.
